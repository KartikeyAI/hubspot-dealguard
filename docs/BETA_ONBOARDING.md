# External beta onboarding

## Ideal tester

- Uses HubSpot Sales Hub with at least 25 open deals.
- Has a documented pipeline and a real sales-to-delivery transition.
- Can provide a Super Admin for installation and one RevOps or sales-operations owner for feedback.
- Is independent of Rokad so the installation can qualify toward Marketplace submission.

## Onboarding call

1. Confirm HubSpot portal, pipelines, sales motion, and required deal fields.
2. Explain the four read-only OAuth scopes.
3. Install DealGuard and add the app card to the default deal record view.
4. Run the initial scan.
5. Review top readiness gaps and tune stale/stage thresholds.
6. Test one deal review and one closed-won handoff.
7. Configure weekly digest recipients.
8. Agree on a two-week feedback checkpoint.

## Success criteria

- At least 80% of active deals are assessed without API errors.
- The customer identifies at least one material pipeline hygiene problem.
- The app card is understandable without training after initial setup.
- False-positive rules can be resolved through settings rather than code changes.
- The customer can confirm a closed-won handoff in under one minute.
