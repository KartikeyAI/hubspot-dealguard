# Commercial Integrity FAQ

**Does this feature read proposal documents?** No. It reads selected CRM properties only.

**Does a high discount mean it is unauthorized?** No. It triggers a deterministic review prompt.

**Does missing quote access break DealGuard?** No. Commercial evidence becomes unavailable while core features continue.

**Are currencies converted?** No. Deal and quote amounts are compared only when the same explicit currency is recorded.

**Does DealGuard change quotes or prices?** No. The slice is read-only and advisory.
