# Review checklist

- Optional scopes are absent from required scopes.
- Missing authorization issues zero commercial object calls.
- Partial authorization reads only the granted source.
- Metadata allowlists exclude proposal and contract content.
- Association pagination is bounded and loop-safe.
- Same-currency checks guard amount comparison.
- Discount language remains non-authoritative.
- Record-only wrapper preserves scan and webhook isolation.
- Deal Brief and action queue include commercial evidence.
- No persistence or migration is introduced.
