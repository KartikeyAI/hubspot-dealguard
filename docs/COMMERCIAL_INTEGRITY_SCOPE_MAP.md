# Commercial Integrity scope-to-value map

| Optional scope | Customer-visible value |
|---|---|
| `crm.objects.line_items.read` | Product/service completeness, quantity and pricing checks, subtotal alignment, recurring-item context, and discount review signals |
| `crm.objects.quotes.read` | Proposal state, amount and currency alignment, expiration risk, issued/accepted evidence, and quote recovery actions |

Neither scope is required for installation. The authorization card explains the feature unlocked before an administrator starts reauthorization.
