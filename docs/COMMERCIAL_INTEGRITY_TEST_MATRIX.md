# Commercial Integrity focused test matrix

- Full optional authorization with aligned line items and accepted quote.
- Missing optional authorization with zero commercial API calls.
- Partial authorization with one source only.
- Independent quote or line-item source failure.
- Bounded association overflow and truncation disclosure.
- Incomplete pricing and amount divergence.
- Expired, rejected, draft, issued, and accepted quote states.
- Quote expiration proximity.
- Same-currency comparison and cross-currency suppression.
- Discount review thresholds and non-authoritative language.
- Deal Brief coverage, attention, status, confidence, and next-action synthesis.
- Record-route isolation and progressive authorization.
