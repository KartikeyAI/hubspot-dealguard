# Enterprise compliance operations

## Audit

- Actor-attributed events
- Old/new value changes where applicable
- Hash-chain integrity
- Search and pagination
- CSV and JSON export
- SIEM forwarding

## Retention

- Configurable retention categories
- Scheduled retention enforcement
- Legal holds
- Hold release approval
- Export-before-delete procedures

## Customer portability

Administrators can generate a complete structured customer export through a secure, single-use download.

## Governance assets

The public release package must include current privacy terms, DPA, subprocessor list, incident-response policy, vulnerability-disclosure policy, backup policy and key-rotation runbook.
