# Enterprise disaster recovery

The disaster-recovery exercise must validate:

- Worker redeployment from source
- D1 restoration
- Secret reconfiguration
- HubSpot OAuth continuity or controlled reauthorization
- Dodo webhook continuity and event reconciliation
- Outbox and billing-usage replay
- Scheduled-job restart
- Synthetic-check recovery
- Customer communication
- Recorded recovery time and recovery point

The exercise must use an isolated environment and sanitized test data.
