- [ ] `rokad.co` verified in the HubSpot developer account.
- [ ] Production app ID and OAuth credentials configured.
- [ ] App logo and screenshots approved.
- [ ] Public docs, privacy, terms, support, and status URLs live.
- [ ] Setup guide tested from a clean portal.
- [ ] Three independent active production installs recorded within the required window.
- [ ] App-card review video recorded.
- [ ] App-card review submitted and approved before listing resubmission.
- [ ] OAuth scopes justified in listing copy.
- [ ] Installation, reauthorization, and removal flows tested.
- [ ] Data-retention and deletion procedure approved.
- [ ] Support process and response targets staffed.
- [ ] Security review completed.
- [ ] Listing category, tagline, screenshots, demo video, pricing, and testing credentials prepared.
