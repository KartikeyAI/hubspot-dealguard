# Release evidence index

The final release PR should link:

- CI workflow run
- HubSpot upload validation
- Dodo test-mode acceptance
- Webhook signature and replay tests
- Usage metering and cap tests
- Role and scope authorization tests
- Policy approval and rollback tests
- Remediation evidence and task tests
- Multi-channel delivery and dead-letter tests
- Audit-chain and export tests
- Backup restore test
- Disaster-recovery exercise
- Legal and Marketplace approvals
